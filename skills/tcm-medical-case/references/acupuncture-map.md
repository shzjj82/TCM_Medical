## 经验口吻的原始表述（医生 raw note 示例）

- 「高血压取曲池，糖尿病取承山，足三里调理中焦气机。」
- 「眩晕多从肝治，曲池、太冲同用，重泻而不留针太久。」
- 「消渴本在阴亏，标在燥热；承山引气下行，配太溪滋水之源。」
- 「中焦气机一转，痰湿自化；不论何病，见苔腻纳差，先取足三里、中脘。」

> 这类口语正是 `doctor_note` 要原样保留的内容——它是带教的价值来源，不要被过度结构化清洗掉。

## 常用穴意对照（供 rationale 字段填充）

| 穴位 | 常配病机 | 取穴用意 |
| --- | --- | --- |
| 曲池 | 肝阳上亢、风热上扰 | 清热降压、疏风通络 |
| 太冲 | 肝气郁结、肝阳上亢 | 平肝熄风、疏肝理气 |
| 承山 | 消渴、湿热下注 | 引气下行、清利下焦湿热 |
| 足三里 | 中焦虚弱、气机不畅 | 调理中焦气机、健脾益气（万能底穴） |
| 中脘 | 胃失和降 | 和胃降逆、运转中枢 |
| 三阴交 | 阴血不足、妇科诸证 | 健脾养血、调肝补肾 |
| 太溪 | 肾阴亏虚 | 滋阴补肾、引火归元 |
| 风池 | 外风/内风犯上 | 祛风通络、清利头目 |
| 百会 | 清阳不升、气虚下陷 | 升提阳气、醒脑开窍 |
| 胰俞 | 消渴 | 调胰腺局部气机（经验穴） |

## 禁忌提醒

- 孕妇禁用合谷、三阴交、肩井、昆仑等；医案中出现「妊娠/孕妇」时走 `safety_alerts` 拦截。
- 出血性疾病禁用刺络放血；晕针史者留观 30 分钟。
