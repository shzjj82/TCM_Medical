# 报告与教学文档模板

## 一、疗效总结报告（`report`）

```markdown
# 中医诊疗总结报告

- 范围：全诊所 / 病人 P2026xxxx
- 周期：YYYY-MM 至 YYYY-MM
- 生成时间：YYYY-MM-DD HH:mm:ss

## 一、总体规模
- 病人总数、诊疗人次、人均诊次

## 二、疗效判定分布
| 判定 | 例数 | 占比 |
（痊愈 / 显效 / 有效 / 好转 / 无变化 / 加重 / 待评估）

## 三、高频病种与证型
| 病名/证型 | 例数 | 常见izing症状 |

## 四、针灸取穴规律 TOP20
| 穴位 | 使用次数 | 主要适应病证 |

## 五、方药使用规律 TOP15
| 方剂 | 使用次数 | 核心病机 |

## 六、典型医案（有效率 ≥ 70%）
- `CASE-Pxxx#Vnn`：初诊 → 末期 摘要

## 七、质量提示
- 未经医师确认（`review_status: pending`）的记录数
- 严重度评分缺失、舌脉记录缺失的记录数

> 本内容由 AI 辅助生成，须经执业医师审核后使用。
```

判定口径（`lib_case._verdict`）：

| 条件 | 判定 |
| --- | --- |
| 末期 ≤ 1 | 临床痊愈 |
| 改善 ≥ 70% | 显效 |
| 改善 ≥ 30% | 有效 |
| 改善 > 0 | 好转 |
| 末期 == 期初 | 无变化 |
| 末期 > 期初 | 加重 |
| 缺评分 | 待评估 |

## 二、教学文档（`teach`）

```markdown
# <病名/证型> · 临床教学文档

- 教学对象：{level}
- 生成时间：...

## 1 病名释义与中西医对应
## 2 病因病机
## 3 辨证要点（舌脉提纲）
| 证型 | 主症 | 舌 | 脉 | 治法 |
## 4 针灸取穴方案（本院经验）
| 主穴 | 配伍 | 手法 | 留针 | 用意 | 来源ID |
> 经验口吻摘录：> "高血压取曲池，糖尿病取承山，足三里调理中焦气机"
## 5 方药运用与加减
## 6 医嘱与生活调摄
## 7 疗效评价与随访节点
## 8 思考题与考核点
## 9 参考资料清单（int/ext/case 编号）
```

## 三、病人对比卡片（`summary --format view`）

```
┌─ 期初情况 · DATE · 严重度 X/10
│  <期初摘要>
└─ 诊疗前基线
      ↓ 经过 N 次治疗（针灸 n 次，中药 m 诊）
┌─ 最新/末期情况 · DATE · 严重度 Y/10
│  <末期摘要>
└─ 第 N 诊后

【疗效判定】<verdict>　严重度变化 Δ　改善幅度 %
【关键转折】第 k 诊（date）：<变化描述>
【期初基线修正记录】...
```

前端实现要点：该区块需在病人详情页**首屏置顶**并高亮（初末期配色对比、严重度用进度条/环形图），下方可折叠时间轴展示每次 followup。
